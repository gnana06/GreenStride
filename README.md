
# 🌱 GreenStride - Sustainable Habit Tracker

GreenStride is a web application that encourages users to adopt eco-friendly habits and track their environmental impact.

## ✨ Features
- Track sustainable daily activities
- Monitor eco-scores and streaks
- Encourage recycling and plastic reduction
- Promote electricity conservation
- Track eco-friendly transportation
- View environmental impact
- Leaderboard and sustainability suggestions

## 🛠️ Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- AWS Elastic Beanstalk

## 🎯 Objective
To encourage sustainable living through daily habit tracking and environmental awareness.
